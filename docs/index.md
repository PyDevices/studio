# studio docs

**Get started.** [Install](get-started/install.md) studio beside the
libraries it uses, then [render a MIDI file](get-started/first-program.md)
through the sound module.

**Guides.** [Play the sound module from a DAW](guides/play-the-sound-module.md),
[run Ostinato](guides/run-ostinato.md), and
[put Vamp on a board](guides/put-vamp-on-a-board.md).

**Reference.** [The sound module's MIDI](reference/sound-module-midi.md): banks,
controllers, System Exclusive, and the `soundmodule.run` options. Vamp's
options are listed at the top of
[`lib/vamp/main.py`](../lib/vamp/main.py).

**How it works.** [What is in studio](how-it-works/overview.md) and
[how it is checked](how-it-works/how-its-checked.md).

**Changelog.** [CHANGELOG.md](../CHANGELOG.md). What is planned is in
[ROADMAP.md](../ROADMAP.md). To work on studio itself, read
[CONTRIBUTING.md](../CONTRIBUTING.md).
